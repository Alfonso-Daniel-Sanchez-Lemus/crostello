# Crostello – Menú y pedidos por WhatsApp

Carta digital de Crostello (Bucaramanga) con carrito que envía el pedido por WhatsApp.

- **Sitio:** HTML/CSS/JS estático en `src/main/resources/static/`. Se publica en GitHub Pages.
- **Menú:** `static/data/menu.json` (productos y precios).
- **Datos del local:** `static/data/config.json` (WhatsApp, dirección, Instagram, mapa).
- **Local con Java 21:** `./mvnw spring-boot:run` y abrir http://localhost:8080
